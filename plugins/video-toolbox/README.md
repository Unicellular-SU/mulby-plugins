# 视频工具箱 (video-toolbox)

轻量级视频处理插件：拖入视频即可完成 **转码压缩、区间剪切、截图抽帧**，无需打开专业剪辑软件。

## 功能

### 转码 / 压缩
- 目标格式：MP4 / MOV / MKV / WebM(VP9) / GIF 动图
- 编码器：H.264（兼容性最好）、H.265（体积更小，Apple 设备自动加 hvc1 标记）
- 画质三档：高画质 / 均衡 / 小体积（CRF 恒定质量编码）
- MP4/MOV 默认 `+faststart`，便于网络播放
- GIF 导出自动生成调色板，12fps、480p

### 剪切
- 在预览播放器上播放到目标位置，按 `I` / `O`（或点击按钮）打入点/出点
- **快速模式**：`-c copy` 流复制，秒级完成，切点对齐关键帧
- **精确模式**：重编码，帧级准确，适合精确卡点

### 截图 / 抽帧
- 当前帧截图：按播放时刻导出 PNG/JPG，可同时复制到剪贴板
- 连续抽帧：按 N 秒间隔批量导出到 `{文件名}_frames/` 目录

### 通用
- 串行任务队列：进度百分比、取消、失败原因展示，完成后可一键定位输出文件
- 输出文件统一写在源视频所在目录，命名带后缀（`_converted` / `_clip_时-分-秒` / `_时-分-秒.png`）
- 首次使用自动引导下载 FFmpeg（由 Mulby 宿主托管），带下载进度

## 触发方式

| 方式 | 操作 |
| --- | --- |
| 关键字 | 搜索「视频工具」「视频转码」「videotoolbox」 |
| 文件 | 将视频文件拖入 Mulby，选择「用视频工具箱打开」 |
| 应用内 | 打开插件后点击「选择视频文件」 |

支持格式：`.mp4` `.mov` `.mkv` `.webm` `.avi` `.m4v` `.flv` `.ts` `.wmv`

> 部分编码（如部分 HEVC/AVI）浏览器无法预览画面，但转码、剪切、抽帧仍可正常执行。

## 依赖

- Mulby 宿主的 FFmpeg API（首次使用会提示下载）
- 无需自行安装任何命令行工具

## 开发

```bash
npm install
npm run build      # 构建后端 + UI
npm run test:unit  # 纯逻辑单测（ffmpeg 参数构造器、格式化工具）
npm run pack       # 打包 .inplugin
```

架构：UI 层（React）直接通过 `window.mulby.ffmpeg` 执行任务；后端仅负责缓存 files 触发传入的文件路径（`getPendingInit` RPC），供 UI 晚启动时兜底拉取。
