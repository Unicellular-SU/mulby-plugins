# 证件安全水印

给身份证正反面、营业执照、银行卡等图片批量添加“仅供办理业务使用”等限制使用标识，降低证件被挪作他用的风险。处理在本机完成，原图不会被覆盖。

## 功能

- 批量导入 JPG、PNG、WebP、BMP（支持 Mulby 附件、文件选择和拖入）。
- 文字水印：自定义文案、颜色、透明度、字号和倾斜角度，默认斜向平铺。
- 图片水印：选择本地 Logo/印章素材，按原图宽度缩放，支持左上、右上、左下、右下、居中或平铺。
- 实时预览：添加图片后显示第一张图片的合成效果，调整文字、图片水印或参数会自动刷新。
- 内置预设：办理业务、入职专用、贷款审核、营业执照报税/年审。
- 输出文件追加 `_watermarked`；PNG/WebP 尽量保持原格式，JPG/BMP 输出为 JPG。

## 使用

1. 在 Mulby 搜索 `图片水印`、`证件水印` 或 `watermark` 打开插件；也可以直接把图片附件交给插件。
2. 添加待处理图片，填写限制使用文案；如需图片水印，选择 PNG 透明 Logo 并设置大小、位置或平铺。
3. 点击“批量添加水印并导出”。新文件写回原图片所在目录，文件名带 `_watermarked`。

## 开发

```bash
npm install
npm run build
npm run pack
```

插件通过 `manifest.json` 声明 `watermark` 和 `watermark-files` 两个 UI 特性；后端 RPC 仅负责读取附件和写出结果，画布合成在插件窗口中完成。
