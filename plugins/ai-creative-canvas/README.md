# AI 创意画布（ai-creative-canvas）

> 无限自由画布上的 AI 影像创作 + 媒体编辑工坊。在一张可无限平移缩放的画布上，以「卡片」为单位**逐张**生成图像 / 文本 / 视频 / 配音，并内置一套**逐卡片媒体后期工具箱**（裁剪 · 扩图 · 抠像 · 放大 · 宫格分镜 · 视频裁剪 · 转 GIF · 抽帧 · 镜头检测 · 音视频分离 · 倒放 · 压制）。

画布引擎**完全自研**（DOM 卡片 + 单一 CSS transform 世界层 + SVG 连线 + 自写图状态，参考 AI-CanvasPro 的实现路线），不依赖任何第三方画布库。

## 与 ai-film-studio 的区别

| | ai-film-studio | **ai-creative-canvas（本插件）** |
|---|---|---|
| 范式 | 故事→分镜→成片的**自动流水线**（一键 Run All） | **自由画布 + 逐卡片按需生成 + 富媒体后期编辑** |
| 画布 | React Flow 流程图 | 自研无限白板（自由摆放/缩放/连线/多画布） |
| 重心 | 编排自动化 | 创作探索 + 媒体编辑工具箱 |

两者定位互补，互不冲突（独立的 id、触发词、存储与落盘目录）。

## 触发方式

在 Mulby 搜索框输入以下任一关键词：

- `创意画布` · `无限画布` · `AI画布`

或把图片 / 视频 / 音频 / 文本文件拖到 Mulby（`img` / `files` 触发），会直接在画布中创建对应卡片。

## 功能

- **无限画布**：滚轮缩放（朝光标）、空格 / 中键拖拽平移、框选多选、拖动、网格、小地图、适配视图、撤销/重做、多画布 Tab。
- **卡片**：文本 / 图片 / 视频 / 音频 / 素材 / 便签 / 分组。可用左侧「导入」、系统拖拽、剪贴板粘贴或 Mulby `img/files` 触发引入资源；图片、视频、音频和文本会自动落为对应类型。
- **节点编辑**：单选生成节点时就地编辑提示词、模型、参数和引用素材；素材节点显示类型、大小、本地定位与替换入口；文本节点区分「生成提示」与可修订的「文本结果」；便签和分组保留更直接的节点内编辑。
- **标注层**：在画布上用画笔 / 形状 / 文字批注（随工程持久化），供审阅与讲解。
- **对齐分布**：拖动时吸附对齐参考线；右键菜单对齐 / 分布多张卡片。
- **AI 生成**（Mulby 原生）：
  - 文本卡：`ai.call` 流式生成（分镜脚本 / 文案 / 提示词扩写），支持看图（引用图片作 vision 输入）。
  - 图片卡：`ai.images` 文生图（流式进度 + 预览）、图生图、多图参考一致性（`referenceAttachmentIds`）。
- **引用**：把一张卡片连线到另一张（拖卡片右侧圆点），或在节点编辑器用 `@` 选素材 / `/` 选预设；生成时 `@名称` 只引用被点名的素材（未 @ 则用全部）。提示词下方会显示「生成引用」预览；无效 @ 会标红并在生成前 toast 提示。
- **图像媒体工具箱**（`sharp` + `ai.images.edit`）：裁剪（框选）、扩图、放大、抠像/去背景、宫格分镜切分（2×2 / 3×3 / 1×3）。
- **视频媒体工具箱**（`ffmpeg`，首次自动下载）：裁剪片段、转 GIF、抽帧、镜头检测（取每个切点代表帧）、提取/去除音轨、倒放、压制。
- **局部重绘**（蒙版 inpaint）：双击图片卡进入局部编辑页，涂抹蒙版区域交模型重绘（`ai.images.edit`）。
- **分镜扇出**：把故事 / 脚本一键拆成多张分镜卡并批量生成（「分镜」面板）。
- **3D 导演台**：three.js 3D 场景摆位、运镜预览与「机位即分镜」工作流；内置 13 套 CC0 独立人物网格（成年男女、少年少女、男童女童、幼儿、老年男女及宽厚 / 健壮 / 纤细 / 丰腴体态）和 20 种姿势。人物资源按工程所需与首次选择加载并在会话内缓存；姿势库会按当前体型生成真实缩略图，支持关节 XYZ 微调、活动范围校验，以及按住 Shift 拖动手腕 / 脚踝进行轻量 IK。控制面板按对象 / 角色 / 镜头分区，支持可调宽侧栏、隐藏滚动条的滚轮与触控滚动、8 个跟随人物朝向或覆盖全场景的语义机位、30% / 50% / 70% 主体占画面推拉、导演视角 / 机位视角切换、冻结机位 PiP、灯光预设，以及可排序的底部机位分镜条。机位可绑定任意场景对象并在对象移动后保持原构图跟随；新机位默认保存人物和道具的走位、朝向、体型、姿势与显隐，切换时可恢复完整镜头，也可只应用相机。连续性检查覆盖跳切、机位反转、焦段 / 画幅 / 灯光突变，以及演员走位、朝向、姿势和入离场变化。镜头面板支持导入 JPG / PNG / WebP 等距柱状全景背景，也可直接选择当前画布已完成的 360 AI 全景；背景会复制为导演工程独立附件。全景可选择 GroundedSkybox 落地环境或无限背景，使用 PMREM 为人物和道具提供环境光，并以 ACES 曝光、地平线、拍摄高度、背景柔化及透明接影面完成校准。环境可保持与主体共用镜头的物理一致模式，也可切换构图适配模式，通过独立环境相机调整背景视觉尺寸而不缩放人物。导演台会保存全景拍摄原点，实时显示相机偏移和视差风险，可一键回到拍摄点；新机位还会保存背景构图模式和尺寸，并在分镜条标记近似透视镜头。环境描述仍会进入生成提示词。顶栏可导入导出便携导演工程 JSON，模型和全景附件会一并打包。另支持逐机位画幅 / 灯光快照、take 历史、批量生成和一键导出分镜到画布。
  - 生成链路是 img2img 软参考（`images.edit` 无强度/控制通道），构图跟随度很大程度取决于模型本身：实测建议优先选构图保持强的编辑模型（如 `google:gemini-2.5-flash-image`），同场景与 gpt-image 系各出 2 张对比后再定默认图像模型。
  - 技巧：镜头区「画幅」选定后抓帧按此裁剪（框内即模型所见）；给人台填「描述」（如"穿长衫的老者"）会按方位自动装配进提示词；要硬约束（严格按深度/骨架构图）需把工程设置的「ControlNet 控制模型」指向真 ControlNet 端点。
  - 视角语义：`机位视角`直接编辑最终出图相机；切到`导演视角`会冻结当前机位，可自由绕场检查摆位，并通过右上角 PiP 监看最终画面；“更新机位”会把当前导演观察角度写回出图机位。
  - 年龄、性别和体态差异已固化为独立网格，运行时不会拉宽、压扁或放大头部来伪造体型；模型加载异常时才回退到程序化人台。体型、姿势和手动关节调整均随工程保存，资产声明见 `THIRD_PARTY_NOTICES.md`。
  - 女性素体采用弱化生理细节的中性胸廓和低对比人台材质；性别与体态主要由脸型、肩胯比例和整体轮廓表达，以降低参考图触发 NSFW 过滤的概率。
- **360 全景**：独立全景卡片类型（文/图生成 2:1 等距柱状）+ 节点内拖动环视预览（可截取视角为新图片卡）+ 接缝/天地修复。
- **可插拔视频/音频生成**（外部 Provider，右上角「设置」配置）：
  - 视频：通用「异步 submit + poll」，按 JSON 路径映射任务 id / 状态 / 结果 URL（兼容 fal、Replicate 风格），支持图生视频。
  - 音频：OpenAI 兼容 `/audio/speech` 配音。
  - API Key 经系统安全存储加密保存。
- **工程库 / 任务中心 / 作品库**：多工程管理与切换；生成任务队列与进度总览；已完成媒体画廊浏览并可定位回画布。
- **模板**：内置工作流模板（文生图链 / 图生视频链 / 分镜扇出），一键铺入画布。
- **持久化**：工程（画布/卡片/连线/视口）自动保存到 Mulby storage；媒体文件落本地磁盘（`<userData>/ai-creative-canvas/media/<projectId>/`）。
- **导出**：选中带媒体的卡片，在节点编辑框点下载图标导出到任意路径。

## 剪辑 vs 时间线

- **画布时间线**（多卡片串片）：编排顺序、转场、混音，适合快速拼成片。
- **剪辑工作台**（单卡精修）：调色、字幕、PiP、特效等非破坏编辑栈，可二次打开继续改。

详见 `docs/2026-07-stabilization-and-convergence-plan.md` 中 WS4 打通计划。

## 前置条件

1. **AI 模型**：在 Mulby「AI 设置 → 模型管理」配置：
   - 至少一个文本模型（文本卡）。
   - 至少一个 **image-generation** 端点类型的图像模型（图片卡 / 扩图 / 放大 / 抠像）。图片卡的模型选择器会自动选中第一个可用图像模型。
2. **FFmpeg**：视频工具首次使用时会自动下载 FFmpeg（带进度提示），无需手动安装。
3. **视频/音频生成 Provider（可选）**：右上角齿轮「设置」新建并配置 Provider + API Key。不配置也不影响核心功能（文/图生图、全部媒体编辑、文本均为 Mulby 原生、零外部密钥）。

## 技术栈

- 前端：React 18 + 自研画布引擎 + zustand（状态）+ Tailwind（面板样式），Vite 构建。
- 后端（host-worker，`src/main.ts`）：承担渲染进程不便/易截断的工作 —— 系统拖拽文件读取与受管目录复制、远程媒体落盘（规避 CORS）、图床 multipart 上传、OpenAI 兼容 TTS 二进制合成、导出落盘。
- Mulby Host API：`ai`（文本/图像/附件）、`sharp`、`ffmpeg`、`http`、`storage`（含 encrypted）、`filesystem`、`system`、`notification`、`theme`、`host`。

## 开发

以下命令**不依赖 Mulby CLI**，克隆后开箱可跑：

```bash
pnpm install       # 安装依赖（pnpm workspace）
npm run typecheck  # 三段 tsc：src / node 配置 / test（test 见 tsconfig.test.json）
npm test           # 编译快照 + store + engine 单测
npm run build      # typecheck → esbuild 后端 → vite UI
```

`dev` / `pack` 需要 **Mulby CLI**（`mulby dev` 热载调试、`mulby pack` 打包 `.inplugin`）。CLI 在同一 workspace 的 `mulby/packages/mulby-cli`，先在该目录构建并全局链接（或把其 bin 加入 PATH）使 `mulby` 命令可用，然后：

```bash
npm run dev   # = mulby dev
npm run pack  # = npm run build && mulby pack
```

## 已知限制

- Mulby 内置 AI 无视频生成、TTS 仅即时播放（不产文件），故**视频生成与配音文件依赖外部 Provider**（已做成可插拔）。
- 为控制 host-worker 内存峰值，远程生成媒体单文件下载上限为 **256MB**，图生视频的图床上传单图上限为 **50MB**。
- 单次本地导入最多 **64** 个文件；文本文件上限为 **5MB**。本地媒体采用后端直接复制，不经前端 Base64 膨胀。
- 镜头检测输出的是每个切点的代表帧（用于快速搭分镜），不直接产出按时间切好的片段。
- 360 全景是独立 pano 卡（v2 迁移自图片卡开关）；渐进式 outpaint 已废弃，见 `docs/360-current-route.md`。
- 单张 360 全景没有真实深度。导演台的落地环境适合固定机位、旋转镜头和小范围移机；大幅推拉、横移或绕拍仍应使用真实 3D 场景、深度代理或其他空间重建资产。
